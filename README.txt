VAHINI WEDDINGS — Bill Generator

Open index.html in Chrome, Edge or another modern browser.
You can also deploy the contents of this folder to Cloudflare Pages as static files.

Features:
- Create invoices, quotations, and receipts
- Client contact, event, and service line items
- Discounts, optional tax, received amounts and remaining balance
- Save/open/duplicate/delete bills locally in the current browser
- Export/import JSON backups
- Print bill or choose "Save as PDF" in the browser print dialog
- Copy summary or share text via WhatsApp

IMPORTANT:
- No backend or account login. Records are stored only in localStorage for this browser/device.
- Export JSON backups frequently. Incognito mode or clearing browser data can remove saved bills.
- PDFs are produced using the browser's Print > Save as PDF option.
- The logo was provided by the user. Company address, phone number, tax registration information and payment details have not been invented. Enter needed details in the notes/payment fields.
- Tax rates are manual. Verify tax requirements and invoice compliance before issuing tax invoices.
